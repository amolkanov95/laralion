# Спецификация: упрощение меню и фильтрация каталога

Дата: 2026-06-02
Проект: Lara Lion (статическая визитка, HTML/CSS/JS, без сборки)
Статус: утверждено к реализации

## Цель

Три связанных изменения интерфейса:

1. Упростить меню навигации до трёх пунктов.
2. Добавить линейку вкладок-фильтров в раздел «Каталог».
3. Реализовать логику фильтрации товаров по категориям на Vanilla JS + CSS с плавной анимацией перестроения сетки.

## Вне объёма

Модальные окна, переключение цветов, прочие секции, структура файлов, латинизация кириллических путей, интеграция Decap CMS — не затрагиваются. Decap/CRUD каталога — отдельный отложенный цикл (см. раздел «Связь с отложенной задачей»).

## 2. Линейка вкладок-фильтров

### Размещение
Внутри `#collections`, между `.gold-divider` и `.collections-grid` (`index.html:186-189`).

### Разметка
Блок `.catalog-filters` с кнопками:

| Подпись | `data-filter` | Активна по умолчанию |
|---------|---------------|----------------------|
| Все | `all` | да |
| Постельное белье | `bedding` | |
| Кухонный текстиль | `kitchen` | |
| Ткани | `fabrics` | |

Кнопки — `<button type="button" class="catalog-filter" data-filter="...">`. Активная несёт класс `is-active`.

### Стиль (новые правила в `css/collections.css`)
- Текстовые кнопки в пастельной гамме сайта, прозрачный фон, без рамок.
- Hover неактивных: плавный переход цвета шрифта в `--accent-gold`.
- Активная вкладка: тонкая матово-золотая линия снизу (приём `::after` из шапки, `header.css:58-76`) + чуть более насыщенный цвет/вес шрифта.
- Токены — существующие: `--accent-gold`, `--transition-normal`. Новые токены не вводятся.

### Адаптив (мобайл, от 320px)
- `.catalog-filters`: `display:flex; flex-wrap:nowrap; overflow-x:auto`, горизонтальный скролл одной строкой.
- Скроллбар скрыт (`scrollbar-width:none` + `::-webkit-scrollbar{display:none}`).
- Горизонтальный скролл самой страницы не появляется.

## 3. Логика фильтрации

### Привязка категорий
Каждой `.collection-card` добавляется атрибут `data-category`. Текущие три товара (`klassika`, `provans`, `sharm`) — постельное бельё: всем `data-category="bedding"`.

### Новый файл `js/catalog-filter.js`
Подключается в `index.html` в блоке скриптов (`index.html:424-429`), инициализация по `DOMContentLoaded`.

### Поведение
1. По умолчанию активна вкладка «Все» → видны все карточки.
2. Клик по вкладке:
   - снять `is-active` со всех вкладок, поставить кликнутой;
   - определить целевую категорию из `data-filter`;
   - **FLIP-анимация перестроения сетки**:
     1. First: запомнить позиции видимых карточек (`getBoundingClientRect`).
     2. Изменить видимость: неподходящие получают класс `is-hidden` (fade-out: `opacity→0`, `scale` вниз), затем выходят из потока сетки; подходящие снимают `is-hidden`.
     3. Last: измерить новые позиции карточек.
     4. Invert + Play: применить обратный `transform`, затем убрать его с `transition` → карточки плавно «переезжают» на новые места. Появляющиеся карточки делают fade-in + восстановление масштаба.
3. Пустая категория (`kitchen`, `fabrics`): подходящих карточек нет → показать заглушку `.catalog-empty` с текстом «Скоро появится». При выборе непустой категории заглушка скрывается.

### Доступность
`prefers-reduced-motion: reduce` → переключение мгновенное, без FLIP и плавных переходов (только смена видимости).

### Координация с существующими анимациями
- Появление секций/карточек при скролле использует классы `fade-in-section` / `visible` (`main.js:95-123`).
- Фильтр использует отдельный класс `is-hidden`, не пересекающийся с `fade-in-section`/`visible`, чтобы анимации не конфликтовали.

## Критерии готовности

1. Меню в шапке и мобильном меню содержит ровно 3 пункта, ведущих на `#collections`, `#about`, `#contacts`.
2. Под заголовком каталога видна линейка из 4 вкладок; «Все» активна при загрузке.
3. Активная вкладка выделена золотой линией снизу; hover неактивных плавно золотит шрифт.
4. Клик по вкладке плавно (FLIP) перестраивает сетку; неподходящие карточки тают, подходящие проявляются.
5. «Кухонный текстиль» и «Ткани» показывают «Скоро появится».
6. На экранах от 320px вкладки прокручиваются горизонтально, страница не получает горизонтального скролла.
7. При `prefers-reduced-motion` переключение мгновенное.
8. Модалки, цвета, скролл-анимации и прочие секции работают как прежде.

## Связь с отложенной задачей (Decap CMS)

Следующим отдельным циклом остаётся ранее согласованное (предварительно) внедрение **Decap CMS + полный CRUD каталога** через единый `products.json` (динамический рендеринг, Вариант A). Текущая фильтрация спроектирована совместимо: она работает с уже отрендеренным DOM карточек, поэтому при переходе на динамический рендеринг логика сохранится — `data-category` будет приходить из данных товара. Эта задача не реализуется без отдельного согласования.
