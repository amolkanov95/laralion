### 4. ИНТЕРАКТИВНЫЕ МИКРО-АНИМАЦИИ (ТАКТИЛЬНЫЙ СЦЕНАРИЙ)

Для создания премиального, «осязаемого» ощущения от интерфейса без перегрузки системы Claude Code должен запрограммировать 4 деликатных эффекта:

#### 1. Инерционный плавный скролл (Smooth Scroll)
*   **Как работает:** Стандартная прокрутка сайта заменяется на мягкую, физичную, с плавным замедлением в конце с помощью легковесной библиотеки (например, *Lenis*).
*   **Эффект:** Создает ощущение тяжести и плавности, имитирующее скольжение тяжелого льняного полотна.

#### 2. Мягкое появление блоков (Fade-in + Blur Reveal)
*   **Как работает:** При прокрутке страницы новые блоки (текст, карточки каталога) плавно проступают на экране через одновременное изменение прозрачности (от 0% до 100%) и уменьшение размытия (от `blur(5px)` к полной четкости).
*   **Эффект:** Имитирует мягкое утреннее пробуждение или естественное рассеивание тумана, идеально соответствуя философии сна.

#### 3. Естественное колыхание цветов (Breeze Effect)
*   **Как работает:** Декоративные акварельные ветки цветов по краям экрана совершают медленные, едва заметные глазу покачивания (вращение всего на `0.5` градуса туда-обратно с циклом в 6–8 секунд).
*   **Эффект:** Создает иллюзию легкого летнего сквозняка из приоткрытого окна спальни.

#### 4. Плавный отклик кнопок и карточек (Micro-interactions)
*   **Как работает:**
    *   При наведении на карточку товара вертикальное фото плавно увеличивается на микроскопические **2%** (`scale(1.02)`), а ссылка-кнопка «СМОТРЕТЬ ->» мягко подчеркивается тонкой золотой линией, растущей из центра.
    *   При вызове всплывающего окна оно появляется плавно, а сайт на заднем плане деликатно размывается (`backdrop-filter: blur(8px)`).
