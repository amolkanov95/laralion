## 🚀 Как разместить сайт

### Вариант 1: Netlify (Самый простой)
1. Перейдите на [netlify.com](https://netlify.com)
2. Перетащите папку `website` в окно браузера
3. Готово! Сайт онлайн с бесплатным HTTPS

### Вариант 2: GitHub Pages
1. Создайте репозиторий на GitHub
2. Загрузите содержимое папки `website`
3. Включите GitHub Pages в настройках

### Вариант 3: Обычный хостинг (Timeweb, Beget, REG.RU)
1. Подключитесь по FTP
2. Загрузите содержимое папки `website` в `public_html`
3. Сайт доступен по вашему домену
